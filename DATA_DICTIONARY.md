# Synthetic data dictionary

All sample values, entities and dates are independently invented. See DATA_POLICY.md.

## quotes.csv

Rows: 24,000. Generated by `run.py`; no missing input values.

| Field | Stored type | Definition |
|---|---|---|
| quote_id | int64 | Unique synthetic quote key; one row per quote. |
| customer_id | int64 | Unique synthetic customer key; one quote per customer in this simplified design. |
| corridor | object | Fictional remittance destination group, not a real commercial corridor. |
| is_new | int64 | 1 = new customer, 0 = returning. |
| send_amount_usd | float64 | USD principal; independent of price assignment. |
| arm | object | Randomized price arm: low/current/high. |
| fee_usd | float64 | Upfront fee in USD. |
| spread_bps | float64 | Synthetic FX spread in basis points; 100 bps = 1%. |
| total_price_usd | float64 | fee_usd + send_amount_usd * spread_bps / 10,000; USD equivalent of total effective charge. |
| price_pct | float64 | 100 * total_price_usd / send_amount_usd; percentage points, not fraction. |
| variable_cost_usd | float64 | Processing cost incurred on a converted transfer: 1 + 0.001 * principal. |
| converted | int64 | Bernoulli 0/1 conversion outcome. |
| revenue_usd | float64 | For pricing: converted * total_price_usd; for geo: conversions * $80; for sessions: basket value if purchased. |
| contribution_usd | float64 | converted * (total_price_usd - variable_cost_usd). No fixed/acquisition cost. |
| split | object | Train/validation randomized in pricing; train/test by phrase family in text. |
